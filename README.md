# 코치조의 ALPHA 육성 센터

## 기능 개요

- **투두 · 루틴**: 목표(카테고리)별로 할 일을 관리하고, 반복할 일은 루틴으로 등록합니다.
- **포모도로 타이머**: 집중과 휴식을 반복하는 타이머로, 끝나면 알림으로 알려 줍니다.

## 다운로드

**[AlphaCenter.dmg 다운로드](https://github.com/kimwonu-bit/Alpha-center/releases/latest/download/AlphaCenter.dmg)** (macOS 26 이상)

1. DMG를 열고 `AlphaCenter`를 `Applications` 폴더로 드래그합니다.
2. 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면, `Applications`에서 앱을 **우클릭 → 열기**를 누릅니다. (그래도 안 열리면 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기")
3. Apple 공증을 받지 않은 앱이라 위의 경고가 뜹니다. 위젯은 개인 서명이라 다른 Mac에서는 안 보일 수 있습니다.

## 커밋 컨벤션

커밋 메시지는 `타입: 내용` 형식으로, 내용은 한글로 한 줄에 간결하게 씁니다.

| 타입 | 용도 |
| --- | --- |
| `feat` | 새 기능 추가 |
| `fix` | 버그 수정 |
| `design` | UI / 디자인 변경 (기능 변화 없음) |
| `refactor` | 동작은 같고 코드 구조만 개선 |
| `docs` | 문서(README 등) 수정 |
| `chore` | 빌드 설정, 스크립트, 리소스 등 기타 작업 |
| `test` | 테스트 추가 / 수정 |

```
feat: 루틴 탭 추가
fix: 완료한 할 일이 아래로 내려가지 않던 문제 수정
design: 일기 표시를 하늘색 글래스 사각형으로 변경
```

- 하나의 커밋에는 하나의 목적만 담습니다.
- 브랜치는 `main`을 기본으로 사용합니다.
